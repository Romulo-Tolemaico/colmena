# Colmena Web (Flutter)

Base de migración del panel web a Flutter.

## Estructura
- `lib/main.dart`: entrada de la app.
- `lib/app.dart`: shell principal, tema e idioma.
- `lib/src/models`: modelos de datos.
- `lib/src/data`: mocks y servicio de datos.
- `lib/src/screens`: pantallas principales.
- `lib/src/widgets`: componentes reutilizables.

## Qué falta conectar
- API real del backend.
- Mapa interactivo real.
- Login / autenticación.
- PDF desde backend.
